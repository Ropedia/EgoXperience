INTRO

TheEgoperienceParadigm

EgoXperience is a full-stack paradigm spanning real-world capture, aligned annotation, unified reconstruction, and benchmarking, turning human experience into world-grounded representations for embodied intelligence.

01 · ENGINE

Ego-Engine

EgoX-Engine transforms captured experience into eight synchronized modalities: RGB, depth, camera poses, MANO hands, object masks, object 6DoF trajectories, metric object meshes, and task captions.

02 · DATA & BENCHMARK

Ego-Data-6M&Ego-Bench

EgoX-Data-6M contains 50 hours and 5.4 million multimodal frames across 270 tasks and 101 objects, spanning workspace, cross-room, and outdoor activities. EgoX-Bench is a quality-controlled one-hour benchmark for joint reconstruction.

03 · MODEL

Ego

EgoX extends the VGGT feed-forward reconstruction paradigm from scenes to egocentric video. From monocular observations and a first-frame object mask, it jointly reconstructs the full system in a shared metric world frame with a single forward pass.
